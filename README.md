## The entry

> We had a meeting to decide whether we need a meeting. The meeting decided: yes, weekly, forever.

## How it works

`main.py` validates the joke (one line, 1–200 characters, no control
characters, no line breaks, no leading/trailing whitespace) and writes it
to `/output/entry.txt`.

Run it with:

```sh
python3 main.py
```
